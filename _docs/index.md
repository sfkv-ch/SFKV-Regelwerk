# Willkommen im Regelwerk der SFKV

Diese Plattform befindet sich im Aufbau und wird schrittweise auf ein neues Dokumentationssystem umgestellt.

---

## 📌 Offizielle Gültigkeit

Die jeweils gültigen Dokumente sind weiterhin auf 👉 [https://www.sfkv.ch/archiv/richtlinien](https://www.sfkv.ch/archiv/richtlinien) veröffentlicht.

Diese Plattform dient aktuell als technische Ablösung und interne Arbeitsbasis.

---

## 🧭 Navigation

Die vollständige Struktur ist über das Menü erreichbar.

Zusätzlich kannst du innerhalb der Dokumente die Kapitel über die Überschriften direkt anwählen.

---

## ℹ️ Hinweis zur Versionierung

Alle Inhalte werden zentral gepflegt und über das interne Repository synchronisiert.

Die jeweils aktuelle Version im System ersetzt schrittweise das bisherige Publikationssystem.
